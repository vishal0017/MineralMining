# Basics of Mineral Mining Modelling, Mapping, and Planning — Open-Source Python Implementation

Reproducible, open-source Python implementation accompanying the book chapter
**"Basics of Mineral Mining Modelling, Mapping, and Planning: An Open-Source
Python Implementation."** It walks through geostatistics (variography,
ordinary kriging, IDW), implicit geological-surface modelling, GIS mapping
(vector layers, grade domains, CRS reprojection), and open-pit mine planning
(cut-off grade theory, grade-tonnage curves, a 3-D floating-cone pit
optimisation, and price sensitivity) on the classic **Walker Lake** teaching
dataset (Isaaks & Srivastava, 1989).

Every figure and table in the chapter is generated by the scripts in this
repository — nothing is hand-drawn or simulated outside the code.

## Dataset

`data/raw/Walker_Lake.txt` is the Walker Lake case-study dataset, bundled
with the open-source [pyLPM](https://github.com/robertorolo/pyLPM) library
(MIT licence) and redistributed here verbatim. It is a classic pedagogical
geostatistics dataset: the "Cu(%)" / "Au(ppm)" labels are a widely used
didactic relabelling of an underlying elevation surface. The *spatial*
statistics (clustering, continuity, anisotropy) are realistic; the absolute
grade magnitudes are illustrative, not an actual assay campaign. See
`LICENSE` for the dataset's attribution/licence note.

## Pipeline

Run the scripts in order (or use `run_all.py` to run all six in sequence).
Each script reads its inputs from `outputs/data/` and writes its own outputs
back there plus any figures to `outputs/figs/`.

| # | Script | What it does | Figures produced |
|---|--------|---------------|-------------------|
| 1 | `01_load_and_qc.py` | Parses the raw GSLIB-format dataset, handles the missing-value code, writes the clean CSV, initial QC plots | fig01, fig02 (overwritten by step 2) |
| 2 | `02_rescale_variography_kriging.py` | Rescales Cu to a realistic porphyry grade range, fits an experimental + spherical variogram (scikit-gstat), runs ordinary kriging (PyKrige) onto a regular grid, 5-fold cross-validation vs. IDW | **Figure 1–4**: histograms, sample location map, variogram, kriging estimate + variance |
| 3 | `03_implicit_surface_modelling.py` | Synthetic borehole contact picks + RBF (thin-plate-spline) implicit-surface interpolation, standalone demo of implicit geological modelling | **Figure 5**: true vs. RBF-interpolated contact surface |
| 4 | `04_gis_mapping_and_cutoff.py` | Builds GeoDataFrames, reprojects to UTM/WGS84, derives grade-domain polygons, a haul-road exclusion buffer; computes mill/pit cut-off grades, grade-tonnage curve, in-situ block economic value | **Figure 6–8**: grade-domain map, grade-tonnage curve, block value map |
| 5 | `05_multibench_floating_cone.py` | Extends the kriged grid into a 3-bench 3-D block model and runs a heuristic floating-cone pit-limit optimisation | **Figure 9–10**: pit outline by bench, vertical cross-section |
| 6 | `06_price_sensitivity.py` | Re-runs the floating-cone optimisation at Cu price ±20% | Sensitivity table (CSV) |

Dependency order: step 2 must follow step 1 (reads/overwrites the same CSV);
steps 4 and 5 both require the rescaled grid from step 2; step 6 requires
the 3-D grade array from step 5. Step 3 is fully standalone.

## Installation

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Tested with Python 3.10+. `geopandas`/`shapely`/`pyproj`/`fiona` pull in
GDAL-backed wheels; on most platforms `pip install` resolves this
automatically, but if it doesn't, installing `geopandas` via conda-forge
(`conda install -c conda-forge geopandas`) is the simplest fallback.

## Running

```bash
python run_all.py
```

or run scripts individually from the repo root:

```bash
python scripts/01_load_and_qc.py
python scripts/02_rescale_variography_kriging.py
python scripts/03_implicit_surface_modelling.py
python scripts/04_gis_mapping_and_cutoff.py
python scripts/05_multibench_floating_cone.py
python scripts/06_price_sensitivity.py
```

Outputs (figures, CSVs, GeoJSON layers, `.npy` arrays) land in
`outputs/figs/` and `outputs/data/`, which are gitignored by default so the
repository stays small — delete the relevant lines in `.gitignore` if you'd
rather version-control the generated artifacts.

## Key open-source libraries used

numpy, pandas, matplotlib, scipy, scikit-learn, scikit-gstat, PyKrige,
GeoPandas, Shapely, pyproj — all cited with full APA7 references in the
accompanying chapter.

## Economic parameters note

Copper price and operating-cost figures used throughout (`PRICE_USD_T`,
`RECOVERY`, `MINING_COST_T`, `PROCESS_COST_T`) are illustrative,
order-of-magnitude figures used to demonstrate the calculations (cut-off
grade theory, grade-tonnage curves, floating-cone pit optimisation, price
sensitivity). They are not a site-specific feasibility study.
